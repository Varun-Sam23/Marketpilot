# MarketPilot

AI-powered pre-market and live market intelligence dashboard.

MarketPilot combines market data, technical analysis, institutional flow, options intelligence, sector intelligence, news research, watchlist ranking, risk analysis, and multi-agent adjudication into one intelligence suite.

## Intelligence network

- Market Agent
- Technical Agent
- News Agent
- Institutional Agent
- Options Agent
- Intraday Agent
- Sector Agent
- Watchlist Agent
- Risk Agent

The system is designed for evidence-first analysis and does not execute trades.
